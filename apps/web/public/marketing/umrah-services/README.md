# Umrah service photography

Source: [Scout Travel Umrah](https://scouttravel.so/umrah/), retrieved 9 November 2026 at the user's request.

These assets show the transport and hotel photographs published on the source page. They are service examples; package inclusions, room allocation and availability remain governed by the selected package.

The four restorations used the built-in image generation tool to improve exposure, color balance and clarity while retaining the original subjects, room arrangements and surroundings. They are AI-restored versions, not unmodified documentary originals. The remaining four photographs were only encoded as WebP. No marketing text, badges or decorative graphics were added to the photographs.

The exact prompt set and generation records are in [image-prompts.json](./image-prompts.json). Unmodified source photographs are archived in `originals/`. All website assets are stored in this directory; the site has no dependency on the generation output folder or the source website.
